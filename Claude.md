# Reglas del Proyecto - Finanzas Personales

## Stack Tecnológico
- **Backend:** Java 17, Spring Boot 3.3.5, Spring Data JPA, H2 / PostgreSQL, BCrypt, JWT.
- **Frontend:** Angular 17 (Standalone Components, Reactive Forms, SCSS).

## Normas para Claude Code
1. Modifica directamente el código en los archivos del proyecto utilizando tus herramientas (`Edit`/`Write`).
2. Mantén las respuestas en la terminal cortas y directas para ahorrar tokens.
3. Antes de ejecutar cambios grandes, verifica que el proyecto compile con `mvn compile` en backend o `npx ng build` en frontend.
